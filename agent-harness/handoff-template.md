# Agent Handoff 模板

每个 agent 完成任务后必须按此格式交接。

```markdown
## Agent Handoff

### Agent
<agent id / name>

### Task
<任务 ID 和任务名称>

### Summary
<本次完成了什么>

### Changed Files
- <path>
- <path>

### APIs / Contracts
<新增或修改的接口、数据结构、配置>

### Verification
<运行过的命令和结果>

### Known Issues
<已知问题，没有则写“无”>

### Risks
<潜在风险，没有则写“无”>

### Next Suggested Task
<建议下一步>
```
