# 极柱Busbar激光焊接

## 1. 概述

极柱 Busbar 激光焊接工位（MW-040）是模组组装中电气连接的核心工序，负责将电芯极柱与 Busbar（汇流排）通过激光焊接实现可靠的低电阻电气连接。Busbar 是电池模组内部的电流汇集与传输导体，通常由镀镍铜板或铝合金板制成，其焊接质量直接决定了模组的内阻、导电效率和长期运行可靠性。

单个模组通常包含数十至上百个焊点——每个电芯的正负极柱均需通过 Busbar 与相邻电芯串联或并联连接。以 1P96S 模组为例，共计 96 颗电芯串接，焊点数量超过 190 个。任何一个焊点的失效（虚焊、脱焊、电阻增大）都可能导致整个模组性能下降或局部过热，甚至引发热失控安全事故。因此，Busbar 焊接对工艺的一致性和可靠性要求极高。

本工位采用光纤激光器（6kW）配合高精度振镜焊接系统，通过同轴视觉实现焊缝自动定位和焊接质量在线监测。焊接方式为搭接穿透焊——激光穿透上层的 Busbar 材料，与下层极柱材料形成熔融结合。设计节拍为 4 PPM，每个焊点焊接时间约 80-150ms。所有焊接参数和焊点质量数据均通过 MES 系统记录，实现每个焊点的全生命周期追溯。

## 2. 工艺流程与技术要点

### 2.1 上料与定位

模组半成品（已完成端板侧板焊接）进入 MW-040 工位后，定位系统采用电芯级视觉定位策略：

- 通过高分辨率 CCD 相机（1200 万像素）拍摄整个模组上表面，AI 算法自动识别每颗电芯的极柱位置（正极通常为铝极柱，负极为铜极柱镀镍）
- Busbar 由供料系统自动放上，通过真空吸附临时固定。视觉系统确认 Busbar 与极柱的对齐度——Busbar 定位孔应与极柱中心偏差 ≤0.15mm
- 定位完成后，压紧机构将 Busbar 紧密压贴在极柱表面上。压紧力 50-100N/焊点，确保上层 Busbar 与下层极柱贴合间隙 ≤0.05mm。贴合间隙过大会导致激光穿透能量损耗，造成未熔合或虚焊

### 2.2 激光焊接工艺参数

Busbar 焊接的工艺参数设计和优化是本工位的核心技术。不同材料组合需要不同的焊接策略：

**铜 Busbar + 铜极柱（负极端）**：
- 铜对 1064nm 激光的吸收率较低（约 5%），因此需要更高的激光功率和更小的光斑尺寸来提高功率密度
- 功率范围：3.0-4.5kW（取决于 Busbar 厚度，通常 0.8-1.5mm）
- 由于铜的高导热性，焊接速度不宜过快，通常 40-80mm/s
- 铜的高反射特性对激光器存在反射光损伤风险，激光器须配备回返光隔离器

**铝 Busbar + 铝极柱（正极端）**：
- 铝对 1064nm 激光的吸收率较高（约 10-15%），焊接效率更好
- 功率范围：2.0-3.5kW
- 焊接速度：60-100mm/s
- 铝焊接主要挑战在于热裂纹倾向和氧化膜的去除

**异种金属焊接（铜-铝）**：
- 铜与铝直接熔焊会生成脆性金属间化合物，严重影响焊点机械强度和导电性
- 一般不推荐直接铜铝熔焊，推荐采用以下替代方案：
  - 超声波焊接或电阻焊（低温连接，不形成金属间化合物）
  - 使用过渡材料（如镍片）作为中间层
  - 设计铆接+导电胶的复合连接方案

### 2.3 焊缝形状与尺寸

Busbar 焊缝通常设计为圆形焊点或短直线焊缝：

- **圆形焊点**：振镜以螺旋线方式填充圆形区域，直径 2-4mm，适用于小面积焊接。多用于圆柱电芯极柱。
- **直线焊缝**：沿 Busbar 长度方向焊接，焊缝长度 20-40mm，适用于方形电芯的平面极柱。
- **穿透深度**：焊缝需穿透 Busbar 并与极柱母材结合，熔深通常控制在 Busbar 厚度的 110-130%，即确保穿透 Busbar 并进入极柱 0.2-0.5mm 但不穿透极柱厚度。

关键控制原则：熔深不足则虚焊风险，熔深过深（穿透极柱）则可能损伤电芯内部结构，引发内短路。

### 2.4 焊接质量在线检测

焊后质量检测分为在线全检和离线抽检两级：

**在线全检**（每个焊点）：
- 使用同轴视觉或旁轴相机拍摄焊点照片，AI 模型分析焊点尺寸、颜色、飞溅等特征
- 采用激光测距或结构光扫描检测焊点高度变化，识别塌陷或凸起缺陷
- 电阻微测法：通过四探针法在线测量焊点电阻，与标准值对比判定合格性

**离线抽检**（每批次/每班）：
- 金相切片分析焊点熔深、熔宽和微观组织
- 拉拔力测试评估焊点强度
- X-Ray 或 CT 检测内部气孔和裂纹

## 3. 参数说明

| 参数 | 说明 | 标准值 | 风险 |
|------|------|--------|------|
| 激光功率（铜 Busbar） | 铜极焊接功率 | 3.0-4.5kW | 功率过低未焊透，功率过高极柱损伤 |
| 激光功率（铝 Busbar） | 铝极焊接功率 | 2.0-3.5kW | 功率不当影响熔深和热裂纹控制 |
| 焊接速度 | 焊点走速 | 40-100mm/s | 过快未熔合，过慢热影响区过大 |
| 焊点直径 | 圆形焊点目标直径 | 2-4mm | 过小电流承载能力不足，过大浪费 |
| 焊缝熔深 | 焊缝穿透深度 | Busbar厚度的110-130% | 不足则虚焊，过深损伤电芯内部 |
| 保护气流量 | 氩气/氮气保护气 | 10-20L/min | 不足导致氧化，过大气流扰动熔池 |
| Busbar-极柱贴合间隙 | 焊接前装配间隙 | ≤0.05mm | 间隙过大致使激光能量穿透损耗 |
| 压紧力 | Busbar与极柱贴合压力 | 50-100N/焊点 | 不足间隙过大，过大压伤极柱 |
| 焊点电阻 | 单个焊点允许最大电阻 | ≤0.05mΩ | 电阻过大增加模组内阻和发热 |
| 节拍要求 | 单模组焊接周期 | ≤15秒 | 超节拍影响整线产出 |

## 4. 常见问题与对策

**Q1：焊接后焊点电阻偏大（>0.1mΩ），排查方向？**
A：焊点电阻偏大通常与焊点有效导电截面积不足有关。排查顺序：首先观察焊点外观——焊点是否明显偏小或呈现不连续状态，若是则为功率不足或焊接时间过短所致。其次，检查 Busbar 与极柱的贴合间隙是否超标（>0.05mm）：间隙过大时，激光能量在间隙中被消耗，实际到达极柱的熔融能量不足，形成"虚焊"。如果焊点外观正常但电阻仍偏大，可能为内部气孔过多——焊前未充分清洁 Busbar 或极柱表面油污所致。

**Q2：焊接铜 Busbar 时频繁出现激光器反射光报警？**
A：铜的高反射率对光纤激光器构成回返光损伤风险。检查激光器回返光隔离器是否工作正常——隔离器通常可承受 100W 量级的回返光功率，但铜的反射可达到入射功率的 80% 以上。优化焊接初始阶段：采用功率缓升策略（前 10ms 内功率从 10% 升至 100%），给铜表面一个"预加热"窗口以建立吸收；也可在焊接起始点施加少量黑色标记物增加吸收率。若问题持续，需考虑改用短波长激光器（如绿光 532nm 激光器），铜对其吸收率高 5-10 倍。

**Q3：铝 Busbar 焊后焊点边缘出现微裂纹？**
A：铝合金的凝固温度区间较宽，热裂纹敏感性高。控制策略：优化焊接终了阶段的功率衰减曲线（收弧阶段功率从 100% 在 50-100ms 内缓降至 0），让熔池有充分时间凝固，释放热应力。可尝试使用脉冲焊接代替连续焊接，通过脉冲之间的短暂冷却减少累积热应力。如果微裂纹持续出现，检查铝合金材料成分——某些合金元素（如铜含量 >4%）会加剧热裂纹倾向，可能需要与 Busbar 供应商协商品质标准。

**Q4：焊点外观正常，但 X-Ray 检测发现内部大量气孔？**
A：气孔来源排查：工件表面油污/水汽 → 加强焊前清洁；保护气体纯度不足或管路泄漏 → 更换高纯氩气并查漏；环境湿度偏高 → 确保焊接区环境湿度 ≤60%RH；母材本身含气量 → 抽样检查 Busbar 板材的氢含量。降低焊接速度、增加摆动幅度也有助于延长熔池保持时间，使气泡充分逸出。

## 5. 安全注意事项

- 激光防护要求与 MW-030 端板侧板焊接相同：激光安全等级为 Class 4，作业区严格隔离管理，配备光密度 OD≥6 的激光防护眼镜，入口安全联锁开关与激光电源连锁控制。
- Busbar 焊接涉及铜、铝、镍等金属的激光加工烟尘，其中铜烟尘（可能含氧化铜微粒）属于国家职业病危害因素范畴，必须通过高效过滤排烟系统有效收集。排烟系统的过滤效率须 ≥99.95%（H13 HEPA 级别），滤芯须按计划定期更换并记录。
- 焊接过程中产生的臭氧（O3）浓度须控制在职业接触限值（0.3mg/m³）以下。作业区须配备臭氧浓度在线监测仪，超过限值时自动加强排风并报警。
- 模组焊接时整组电芯已堆叠完成，虽然激光焊接不直接作用于电芯本体，但焊接热传导可能对电芯产生温升影响。须通过工艺设计确保电芯极柱根部温度不超过 80°C。首次量产前须进行焊接热影响测温验证试验，确认安全余量。
- 焊后模组的个别焊点可能处于高温状态（200-400°C），下料时操作人员须注意防止烫伤。下料传送带在焊后1米区域配备冷却风扇和"高温表面"警示标识。
