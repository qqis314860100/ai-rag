# 计划文档（Plans）

长期工作流的计划与执行记录，供开发与 AI Agent 追溯"正在做什么、做过什么"。

## 目录约定

| 目录 | 用途 |
|------|------|
| `docs/plans/active/` | 进行中的计划/里程碑。每个计划一个文件，包含目标、范围、验收标准、当前进度 |
| `docs/plans/completed/` | 已完成的计划。完成后将 active 中的文件移入并标注完成日期 |

## 使用规则

1. 新计划（跨多个 commit/多轮迭代的工作）先在 `active/` 建计划文档，再动手。
2. 计划文档需包含：目标、范围边界、验收标准（Definition of Done）、风险。
3. 完成验收后移入 `completed/`，文件名保留，开头标注完成日期。
4. 一次性小改动（单 commit）不需要计划文档。
