# 聊天页 UI 修复验收

## 本轮目标

根据第一轮 Impeccable UI 审查清单，优先修复影响信任感和可读性的 P0/P1 问题：

1. 移动端布局不再被全局侧栏和右侧工作台挤坏。
2. 普通笔记本宽度下，右侧知识工作台不再默认常驻压缩主阅读区。
3. 回答下方整理动作降低 AI 装饰感，改为更克制的企业工具操作栏。
4. Artifact 卡片减少 badge 噪声，突出类型、标题、状态、可信度和证据。
5. 图解和 artifact 弹窗在移动端使用全屏壳，减少窄屏溢出压力。

| 断点 | 验收项 | 结果 |
