# 聊天体验重构需求文档

> 目标：把当前聊天区从“可用”重构到“可持续扩展且信息层级正确”的状态。

## 1. 背景

当前聊天页已经具备基础问答能力，但存在几个结构性问题：

- 右侧栏承载了过多“引用文章”信息，无法随着会话引用量增长而扩展。
- 问答卡片的操作语义不清，用户消息和助手消息的可操作项混在一起。
- 引用、预览、笔记、章节导航没有分层，信息拥挤。
- 文件预览能力不足，无法统一承载 `md`、`pdf`、`html`、代码块等标准化内容。
- 对话结果缺少可视化结构化输出能力，例如思维导图、流程图、时序图。

## 2. 目标

1. 聊天区作为主任务入口，保持简单、清晰、可打断。
2. 引用只作为“答案证据”按需打开，不做全量常驻展示。
3. 右侧栏只负责“当前对话上下文导航”，不是引用仓库。
4. 文件预览支持标准格式统一展示。
5. 支持把对话内容进一步整理成思维导图、流程图等结构化视图。

## 3. 产品原则

- 主任务优先：聊天与回答优先于证据浏览。
- 证据按需展示：引用默认折叠，点击再展开。
- 信息分层清晰：回答、引用详情、会话上下文三层分离。
- 操作可控：生成中可中断，不用转圈代替控制。
- 语义一致：用户消息、助手消息、引用详情各自只保留合理操作。

## 4. 范围

### 4.1 本期要做

- 聊天消息卡片操作重构
- 引用详情弹窗/抽屉
- 右侧栏改成会话导航器
- 统一文件预览器
- AI 结构化图谱入口
- 输入框发送/中断状态重构

### 4.2 本期不做

- 彻底重写整个知识库管理页
- 变更底层认证模型
- 重构全部文档管理数据结构
- 做成通用低代码编辑器

## 5. 功能需求

### 5.1 问答卡片

#### 用户消息

- 悬浮显示 `复制 / 编辑 / 删除本轮`
- 删除必须二次确认
- 删除语义应明确为“删除这一轮问答及其后续分支”

#### 助手消息

- 悬浮显示 `复制 / 点赞 / 点踩 / 收藏 / 重新生成 / 查看引用`
- 不提供删除按钮
- 点赞和点踩都必须可回收/可切换

#### 流式状态

- 发送后按钮变为“中断”而不是 loading 转圈
- 中断后保留已生成内容
- 中断后输入框可继续编辑并再次发送

### 5.2 引用系统

- 回答正文中的引用编号可点击。
- 点击后打开引用详情弹窗或右侧抽屉。
- 引用详情必须展示：
  - 文档名
  - 章节路径
  - 相关度
  - 原文片段
  - 前后文上下文
  - 操作按钮
- 引用详情支持：
  - 跳转原文
  - 复制引用
  - 收藏证据
  - 加入笔记
  - 生成图谱

### 5.3 右侧栏

右侧栏不再展示全量引用列表，而是作为“会话导航器”：

- 章节树
- 已讨论章节
- 学习笔记
- 最近证据
- 收藏证据
- 当前对话脉络

### 5.4 文件预览

统一预览器需支持：

- `Markdown`
- `PDF`
- `HTML`
- 代码块 / 纯文本
- 原始文本模式

要求：

- 预览器有统一外壳，内部按内容类型切换。
- `HTML` 预览必须做清洗和隔离。
- `PDF` 支持页码、缩略定位、跳转。
- `Markdown` 支持标题、列表、表格、代码块、链接。
- `Code` 支持语法高亮。

### 5.5 对话结构化输出

支持从以下来源生成结构化图谱：

- 整个会话
- 某一轮回答
- 某条引用

支持图谱类型：

- 思维导图
- 流程图
- 时序图
- 章节树视图

### 5.6 学习笔记

- 支持在当前会话中记录笔记。
- 支持从引用详情一键加入笔记。
- 支持按章节和引用归档。

## 6. 前端职责

- 重新拆分聊天消息卡片操作区。
- 实现引用详情弹窗/抽屉。
- 将右侧栏改成会话导航器。
- 实现统一文件预览组件。
- 实现图谱视图入口和展示。
- 重构输入框发送/中断按钮状态。

## 7. 后端职责

- 提供消息删除的级联语义。
- 提供引用详情所需的上下文数据。
- 提供笔记增删改查接口。
- 提供结构化预览内容接口。
- 提供图谱生成所需的数据聚合接口。

## 8. RAG 职责

- 返回更完整的检索元数据：
  - chunk
  - document
  - section
  - score
  - 上下文片段
- 支持引用详情所需的前后文窗口。
- 支持从会话摘要中抽取结构化节点。
- 为图谱生成提供输入结构，而不是直接绑死某一种图形渲染。

## 9. 验收标准

- 引用不再以全量侧栏列表形式常驻。
- 用户消息删除必须二次确认。
- 助手消息不提供删除。
- 发送中按钮可中断。
- 文件预览至少支持 `md/pdf/html/code`。
- 右侧栏可用于章节导航和笔记。
- 能从对话或引用生成图谱。
