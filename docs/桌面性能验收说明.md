# 桌面性能验收说明

本项目的桌面端性能验收使用 `pnpm run smoke:desktop-perf`。它用于发布前或高影响 UI 改动后记录基线，不替代完整压测。

## 默认基线

默认模式不依赖浏览器自动化，会记录：

- `web_first_byte`：Web 首字节耗时。
- `web_html_complete`：HTML 下载完成耗时。
- `chat_first_sse_event`：聊天 SSE 首个事件耗时。
- `chat_first_token`：首 token 耗时。
- `chat_full_answer_saved`：完整回答保存耗时。
- `diagram_queue_ack`：图解异步任务入队耗时。
- `diagram_open_ready`：图解从入队到 ready 的耗时。
- `long_thread_data_baseline`：长会话数据整形的低成本基线。

运行示例：

```bash
pnpm run smoke:desktop-perf -- --web http://localhost:5174 --api http://localhost:3001
```

## 浏览器模式

如果本机安装了 Playwright，可以追加 `--browser`，脚本会补充：

- `browser_first_screen`：真实浏览器进入聊天页并等到输入框可用的耗时。
- `browser_long_thread_scroll`：注入长会话内容后的滚动基线。

```bash
pnpm run smoke:desktop-perf -- --browser
```

若未安装 Playwright，浏览器指标会标记为 `skipped`，默认 API 与异步产物指标仍可使用。
