# 端板侧板激光焊接

## 1. 概述

端板侧板激光焊接工位（MW-030）是模组组装产线中至关重要的结构连接工序，负责将堆叠固化后的电芯组通过端板和侧板的激光焊接固定为一个整体模组框架。端板（End Plate）位于模组两端，提供纵向约束和安装接口；侧板（Side Plate）位于模组两侧，提供横向约束和防护。两者通过激光焊接连接，形成刚性框架结构，确保模组在后续装配、运输和使用过程中结构稳定。

本工位采用光纤激光器作为光源，额定输出功率 6kW，配合高精度扫描振镜实现快速、精准的焊缝成型。激光焊接相较传统电弧焊和电阻焊具有热输入小、焊缝深宽比大、热影响区窄、焊接速度快等显著优势，特别适合电池模组对低热影响和精密尺寸控制的要求。MW-030 工位设计节拍为 4 PPM，配备同轴视觉监控和焊缝跟踪系统，可实时检测焊接过程并对焊缝质量进行在线评估。

焊接质量是模组结构安全的基础保障。端板与侧板间的焊缝需要承受模组在振动、冲击工况下的机械载荷，同时须确保在模组全生命周期内不产生裂纹或疲劳失效。因此，焊接工艺参数的设计和过程控制是本工位的核心技术难点。

## 2. 工艺流程与技术要点

### 2.1 来料与定位

堆叠固化后的电芯模组半成品由传送系统送入 MW-030 上料位。在此之前，端板和侧板已由自动化供料系统完成上料，并经 CCD 视觉系统完成外形尺寸、表面质量和方向确认。

定位夹具对工艺精度起决定性作用。模组夹具采用零点定位系统，可实现 ±0.02mm 的重复定位精度。夹具的关键特征包括：

- 电芯组定位基准面：以电芯大面为第一基准，确保焊接时极柱位置的一致性
- 端板压紧机构：气动+机械协同压紧，端板与电芯端面间隙控制在 ≤0.1mm
- 侧板压紧机构：多点伺服压紧，压力逐点可调，消除侧板与电芯组间的装配间隙
- 防焊接变形夹持：在焊缝附近设置辅助压紧点，抑制焊接热变形

### 2.2 激光焊接工艺

激光焊接是本工位的核心技术。工艺参数设计遵循以下原则：

- **激光功率**：根据板厚和材料选择。端板和侧板通常为铝合金（AL6061 或 AL3003），板厚 1.5-3.0mm。焊接功率范围 3.5-5.5kW，功率密度需达到 10^6 W/cm² 以上才可形成深熔焊（Keyhole）模式。
- **焊接速度**：一般为 60-120mm/s。速度过低会导致热输入过大、焊缝过宽、热影响区增大；速度过高则可能未焊透或产生气孔。焊接速度与激光功率需匹配，线能量（功率/速度）控制在 40-70J/mm。
- **离焦量**：焦点位于工件表面或表面以下 0.5-1.0mm（正离焦），以获得最佳的熔深和熔宽比例。离焦量通过视觉高度传感器自动补偿。
- **保护气体**：使用高纯氩气（纯度 ≥99.999%）作为保护气体，流量 15-25L/min，通过同轴喷嘴或侧吹方式覆盖熔池，防止焊缝氧化和气孔生成。

焊接路径设计：端板与侧板的焊接通常为角接或搭接接头形式。振镜沿焊缝路径摆动扫描，摆动幅度 0.5-1.5mm，摆动频率 100-300Hz，以改善焊缝成型、减少气孔和裂纹。

### 2.3 在线质量监控

焊接质量监控系统包括：

- **同轴视觉监控**：CCD 相机通过焊接光路同轴观察熔池形态，实时检测飞溅、塌陷、未焊透等缺陷特征。AI 算法对熔池图像进行分类，识别准确率 ≥98%。
- **激光功率监测**：光电传感器实时检测工作面上的实际激光功率，偏差超过 ±2% 触发报警。
- **保护气体流量监测**：电子流量计实时监测保护气流量，低于设定下限时中断焊接。
- **焊接位置跟踪**：激光位移传感器沿焊缝方向检测工件高度变化，动态调整焦点位置。

### 2.4 焊后检验

焊接完成后，模组半成品进入焊后检验工序。检验项目包括：

- **外观检查**：目视或 AI 视觉检查焊缝表面成形质量，无裂纹、飞溅、咬边、未填满等缺陷
- **焊缝熔深检测**：采用相控阵超声检测（PAUT）对关键焊缝进行熔深和内部缺陷检测，检测覆盖率 100%
- **拉力测试**：每批次抽检样件进行破坏性拉力测试，焊缝强度须不低于母材强度的 90%

## 3. 参数说明

| 参数 | 说明 | 标准值 | 风险 |
|------|------|--------|------|
| 激光功率 | 光纤激光器输出功率 | 3.5-5.5kW | 功率不足未焊透，功率过大烧穿母材 |
| 焊接速度 | 焊缝行进速度 | 60-120mm/s | 速度过快未焊透，过慢热变形大 |
| 线能量 | 单位长度焊缝能量输入 | 40-70J/mm | 过高引起热变形和组织粗化，过低熔深不足 |
| 离焦量 | 焦点相对工件表面的偏移 | 0 至 +1.0mm | 离焦不当影响熔深和熔宽 |
| 保护气流量 | 氩气保护气流量 | 15-25L/min | 流量不足焊缝氧化变色，过大造成紊流 |
| 保护气纯度 | 氩气纯度要求 | ≥99.999% | 纯度不足焊缝氧化、气孔增多 |
| 摆动幅度 | 振镜光束摆动宽度 | 0.5-1.5mm | 幅度过大焊缝过宽，过小搭桥不足 |
| 摆动频率 | 振镜光束摆动频率 | 100-300Hz | 频率不当中出现波纹或未熔合 |
| 夹具定位精度 | 模组夹具重复定位精度 | ±0.02mm | 定位偏差导致焊点位置偏离 |
| 节拍要求 | 单个模组焊接周期 | ≤15秒 | 超节拍影响下线节拍 |

## 4. 常见问题与对策

**Q1：焊接过程中出现气孔或表面气孔密集，如何解决？**
A：气孔的主要成因包括：保护气体流量不足或喷嘴堵塞导致空气卷入、工件表面油污或水汽未清洁干净、焊接速度过快导致熔池气体来不及逸出。对策：检查并清洁保护气喷嘴，确保气体管路无泄漏；加强焊前工件清洁（用异丙醇或丙酮擦拭焊接区域）；适当降低焊接速度或增加摆动幅度以延长熔池存在时间，利于气体逸出。

**Q2：焊缝外观发黑或发黄，呈现严重氧化？**
A：这是保护气覆盖不充分的典型表现。首先检查保护气体纯度和流量是否达标——氩气纯度不足 99.999% 时焊缝极难保持银白色；其次检查气路各接口是否有泄漏，可使用氦气检漏仪进行查漏；最后确认同轴喷嘴位置是否偏移，造成气流偏离熔池区域。如使用侧吹方式，须确认侧吹角度和高度是否符合工艺设定。

**Q3：相控阵超声检测发现焊缝内部存在未熔合缺陷？**
A：未熔合通常与激光功率不足、焊接速度过快或离焦量不匹配有关。逐步排查：用激光功率计校准实际输出功率，确认与设定值一致；降低焊接速度 10-20% 试焊验证；调整离焦量至最佳位置（可通过阶梯试板试验确定）。如果特定批次材料出现普遍性未熔合，须检查材料的激光吸收率是否有变化——不同批次的铝合金表面状态可能影响对激光的吸收。

**Q4：焊接热变形导致模组尺寸超差？**
A：焊接热变形控制应多管齐下：优化焊接顺序——采用对称焊接或跳焊策略，使热应力分布均匀；增加冷却等待时间——在两段连续焊缝之间设置冷却间隔（0.5-1秒）；优化夹具设计——在焊接区域 10mm 范围内增加辅助压紧点；如变形仍不可接受，可采用预变形补偿策略——夹具在夹紧时施加反向预变形，焊接冷却后恢复至目标尺寸。

## 5. 安全注意事项

- 激光焊接作业区必须设置独立隔间，墙体采用防激光辐射材料覆盖。入口安装安全联锁门，门开即切断激光电源。作业区外须安装醒目的激光警示灯（红色）和警示标识。
- 所有进入激光作业区的人员必须佩戴与激光波长匹配的防护眼镜。对于 1064nm 波长的光纤激光器，防护眼镜的光密度（OD）须 ≥6。防护眼镜须定期检查镜片是否划伤或老化，一旦影响防护性能立即更换。
- 激光焊接产生金属烟尘和有害气体（如铝粉尘、臭氧），作业区须配备高效排烟除尘系统，排烟口尽可能靠近焊点（距焊点 ≤100mm）。排风系统的过滤芯须定期更换，以维持额定排风量。操作人员须佩戴防尘口罩（KN95 或以上级别）。
- 激光加工过程中可能产生反射和散射激光，须确保所有工装夹具表面采用黑色阳极氧化或喷砂处理，降低激光反射率。光路附近不得放置镜面反射物品。
- 紧急停止按钮须在激光焊接间的入口内侧和外侧均设置，间距不超过 3 米。紧急停止后，激光器须立即关闭，同时保护气体须继续供应 1-2 秒以保护焊点和光学元件。
