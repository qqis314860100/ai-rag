# 电芯分选

## 1. 概述

电芯分选是动力电池 Pack 生产线的第一道核心工序，承担着对所有来料电芯进行性能测试与等级分类的关键职责。电芯作为 Pack 的基本组成单元，其一致性直接影响模组乃至整个电池系统的容量发挥、循环寿命和安全性。同一模组内各电芯的电压、内阻、容量等参数的离散程度如果过大，将导致短板效应——性能最差的电芯限制整个模组的充放电能力，甚至引发局部过热和安全隐患。

本工位（CS-010）设计处理节拍为 12 PPM（Pieces Per Minute），即每分钟可完成 12 颗电芯的全面测试与分选。电芯来料首先经过外观自动检测，剔除存在划痕、鼓包、漏液等明显缺陷的个体，然后进入 OCV（Open Circuit Voltage，开路电压）测试、交流内阻（ACR）测试和 K 值（自放电率）测试三个核心测量环节。根据预设的分档规则，电芯被自动分配至不同的分选通道，为后续的模组堆叠工序提供高度一致的电芯组。

电芯分选的精度不仅取决于测试设备的性能，还与测试环境的温湿度控制、电芯静置时间、测试夹具的接触电阻等密切相关。因此，本工位配备有恒温恒湿环境控制系统，并制定了严格的操作规程和点检标准。

## 2. 工艺流程与技术要点

### 2.1 来料外观检测

电芯进入分选线后，首先通过 CCD 视觉检测系统对电芯六面进行全方位成像检查。检测项目包括但不限于：铝塑膜表面划痕（深度 ≤0.1mm）、壳体凹陷或凸起、极耳弯折或氧化、绝缘片完整性、喷码清晰度等。不合格品由剔除气缸自动排入 NG 通道。CCD 系统的检测精度为 ±0.05mm，误判率控制在 0.5% 以内。

### 2.2 OCV 开路电压测试

开路电压是电芯荷电状态（SOC）的直观反映。采用四线制凯尔文连接方式，消除测试引线和接触电阻引入的测量误差。测试仪表精度要求为六位半数字万用表，电压分辨率达到 1μV。每颗电芯的 OCV 需在 3.6000V 至 4.2000V 区间内，超出范围的电芯直接判为不合格。

关键控制点：电芯须在分选前至少静置 4 小时（自化成分容结束起算），以确保电压稳定；测试夹具的接触力控制在 100±20N，过大的接触力可能损伤极耳，过小则接触不良导致误测。

### 2.3 交流内阻测试

内阻是衡量电芯功率性能和老化程度的关键指标。采用 1kHz 交流信号进行内阻测量，测试电流为 10mA。交流内阻标准值通常为 0.5-2.0mΩ（具体视电芯型号而定）。同组电芯内阻差异须控制在 ±0.05mΩ 以内。

技术要点：内阻测试对温度敏感，环境温度需恒定在 23±2°C；电芯表面不得有冷凝水或油污；测试前需用干洁无尘布擦拭极柱表面。

### 2.4 K 值自放电测试

K 值（Voltage Drop Rate）反映电芯的自放电程度，单位通常为 mV/day 或 μV/s。通过测量电芯在固定时间间隔内的电压下降值来计算。考虑到产线节拍，本工位采用加速测试方法：将电芯静置于 45°C 环境中 2 小时，测量静置前后的电压差值，换算为标准 K 值。K 值合格标准 ≤0.2mV/day，K 值过大的电芯存在内部微短路风险，直接判定为不合格。

### 2.5 分档与配组

综合 OCV、内阻、K 值三项指标，电控系统按照预设的分档规则进行自动分选。分档规则通常设定为：OCV 分档精度 ±2mV，内阻分档精度 ±0.03mΩ，K 值分档精度 ±0.03mV/day。分选后同档电芯存入独立料仓，由 MES 系统记录每颗电芯的完整测试数据和归属料仓编号，实现单体级追溯。

## 3. 参数说明

| 参数 | 说明 | 标准值 | 风险 |
|------|------|--------|------|
| 电芯静置时间 | 自分容结束至分选测试的间隔时间 | ≥4 小时 | 静置不足导致电压不稳定，误判分档 |
| OCV 合格范围 | 开路电压允许区间 | 3.6000-4.2000V | 超范围电芯可能过充或过放损坏 |
| 交流内阻合格范围 | 1kHz 交流内阻允许值 | 0.5-2.0mΩ | 内阻过大发热严重，导致寿命衰减 |
| K 值合格上限 | 自放电率最大允许值 | ≤0.2mV/day | 超过上限提示内部微短路风险 |
| 同组内阻允差 | 同一配组内阻最大差值 | ≤0.05mΩ | 差异过大会导致模组内电流不均衡 |
| 测试温度范围 | 分选测试环境温度 | 23±2°C | 温度偏离影响内阻和OCV测量精度 |
| 环境湿度 | 测试环境相对湿度 | ≤10%RH | 湿度过高可能导致极耳氧化 |
| 夹具接触力 | 测试夹具对极耳施加的压力 | 100±20N | 压力不足导致接触不良，过大损伤极耳 |
| 节拍要求 | 单颗电芯测试周期 | ≤5秒 | 超节拍影响整线产能 |

## 4. 常见问题与对策

**Q1：电芯 OCV 读数明显偏离正常值，但外观无异常，如何排查？**
A：首先检查测试夹具接触是否良好，用无水酒精清洁夹具触点；其次确认电芯静置时间是否达标（≥4 小时）；如以上均正常，使用手持万用表进行独立复测，以排除自动化测试系统故障。若复测仍异常，将该电芯隔离并追溯其化成分容历史数据。

**Q2：内阻测试值波动较大，同一电芯重复测试结果不一致？**
A：排查温湿度控制是否稳定，环境温度波动会导致内阻显著变化（温度每升高 1°C，内阻降低约 2-3%）。检查测试线缆是否老化或松动，推荐每周进行一次标准电阻校准。还需确认电芯表面是否有冷凝水或油污——即使轻微的表面污染也会显著影响 1kHz 交流测量信号的耦合。

**Q3：K 值批量偏高，超出正常范围？**
A：首先核实加速测试温度和时间是否准确（45°C/2h），温控箱可能存在校准偏差。其次确认来电批次是否一致——不同批次电芯的化成工艺差异可能导致自放电特性偏差。如核实为工艺波动，须通知来料检验（IQC）加强对该批次的抽检比例，并通知电芯供应商排查化成工艺。

**Q4：分选机的分档通道频繁堵塞怎么办？**
A：检查料仓料位传感器是否误报，确认气动推杆的动作行程和速度是否正常。定期清洁分选通道滑轨，避免粉尘积聚增加阻力。建议每班次进行一次清空吹扫，每周进行一次通道磨损检查。如遇电芯外形尺寸异常（如轻微鼓包），应及时反馈来料端排查。

## 5. 安全注意事项

- 电芯存储和分选区须维持恒温恒湿环境，防止电芯受潮或过热引发安全风险。区域配备 VESDA 极早期烟雾探测系统和二氧化碳自动灭火装置，温控系统设置超温（>40°C）自动断电保护。
- 分选机内部涉及高速运动机构（气动推杆、传送带），运行过程中严禁将手或工具伸入设备内部。所有设备检修和维护操作必须执行上锁挂牌（LOTO）程序，切断气源和电源后方可进行。
- 电芯搬运和操作时须轻拿轻放，严禁抛掷、挤压或刺穿电芯。使用防静电手环和防静电鞋，操作台面铺设防静电胶皮（表面电阻 10^6-10^9Ω），避免静电放电损伤电芯内部结构。
- 异常电芯（鼓包、漏液、严重发热）须立即隔离至专用防火防爆安全柜中，按照危废处理流程由专业人员处置。漏液电芯可能释放有毒和易燃气体，隔离区须配备局部排风系统。
- 操作人员上岗前须完成锂电池安全知识培训，熟悉电芯热失控的早期识别信号（异常发热、冒烟、鼓包等），掌握灭火器使用和应急疏散路线。
