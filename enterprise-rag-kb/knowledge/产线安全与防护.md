# 产线安全与防护

## 1. 概述

电池产线是一个集高电压、高功率激光、化学品使用、重型物料搬运和自动化设备运行为一体的复杂制造环境，安全风险种类多、危害程度高、管控难度大。产线安全管理遵循"安全第一、预防为主、综合治理"的方针，以 OHSAS 18001 / ISO 45001 职业健康安全管理体系为框架，构建覆盖全员、全过程、全方位的安全管理体系。

产线主要安全风险分类包括：激光辐射危害（Class 4 激光器）、高压电气危害（最高 3060V DC 耐压测试）、化学品危害（环氧树脂、胺类固化剂、有机溶剂）、机械危害（机器人、传送带、AGV）、火灾爆炸危害（锂电池热失控、金属粉尘）、以及职业健康危害（焊接烟尘、噪声、人机工程学风险）。每一种风险类型均须制定专项管控方案，包括工程控制措施、管理控制措施和个体防护装备（PPE）三个层级。

安全管理实行三级责任制：公司安全委员会负责制定安全方针和投入资源；产线安全工程师负责日常监督检查、风险评估和安全培训；班组安全员负责本班组的每日安全点检、隐患报告和应急响应。新员工须通过三级安全教育（公司级、部门级、班组级）并通过考核后方可上岗，转岗员工须接受新岗位的专项安全培训。每年至少组织一次全员安全知识更新培训和一次综合应急演练。

## 2. 激光辐射安全

### 2.1 激光危害等级与分区

产线使用四台 6kW 连续光纤激光器，属于 Class 4 激光产品（最高危险等级），其直射光束、镜面反射光和漫反射光均可对眼睛和皮肤造成永久性不可逆的损伤。激光安全基于以下措施：

- **封闭隔离**：每台激光焊接设备的工作区域用防激光辐射防护材料（OD≥6 @ 1064nm）完全封闭，形成光学密封的工作腔体。激光防护材料须定期检查——面板有无变形、穿孔或老化变色。
- **入口安全管理**：激光工作间入口设置安全联锁开关，门开启时激光器电源自动断开。联锁开关的可靠性须每周测试一次。入口门外设置红色激光警示灯，激光工作时持续亮起。
- **观察窗**：激光工作间的观察窗采用复合结构——激光防护玻璃（OD≥6）+ 外层钢化玻璃保护，确保在防护玻璃意外破裂时仍有外层保护。
- **光路安全**：激光传输光纤外部采用不锈钢铠装保护，防止光纤意外断裂后激光束无序射出。光纤弯曲半径须 ≥200mm，避免光纤在弯曲处断裂。

### 2.2 激光防护眼镜管理

所有进入激光区域的人员（操作工、设备维护人员、参观人员）必须佩戴与 1064nm 波长匹配的激光防护眼镜：

- **光密度要求**：OD≥6（防护眼镜能将 10^6 倍的光能量衰减，将 6kW 激光在被防护镜遮挡后落到人眼上的功率降至安全以下）
- **镜片检查**：每次使用前检查镜片是否有划痕、裂纹、变色或镀膜脱落。有损伤的防护镜立即更换。
- **定期标定**：激光防护眼镜的有效期通常为 3 年（取决于材料和使用频率），过期或无法确认有效期的眼镜不得使用。镜片的实际防护性能应由厂家定期送检并提供检测报告。

## 3. 高压电气安全

### 3.1 高压区域管理

产线涉及高压电气的区域包括：MW-030/MW-040 激光焊接设备内部电源、MT-050 模组 EOL 测试柜（最高 3060V DC）、PT-070 Pack EOL 测试柜（最高 800V+系统级电压）、以及 Pack 总装工位的通电测试环节。

- **高压区域标识**：所有高压设备的外部贴有"高压危险"警告标识，高压接线端子和内部高压区域用黄色警示标签标注。
- **接地保护**：所有高压设备的金属外壳和可导电部分必须可靠接地，接地电阻 ≤0.1Ω。接地系统须每半年检测一次，检测结果存档。
- **绝缘防护**：高压连接器和电缆须有双重绝缘或加强绝缘设计。兆欧表测试的绝缘电阻须 ≥100MΩ（500V DC 测试电压下）。测试电缆、探针、夹具的绝缘须在每班次使用前做外观检查。
- **放电程序**：高压测试完成后，设备须通过放电回路自动放电。操作人员须在接触高压部件前使用高压验电器确认无残留电压（残留电压 ≤5V）。无电压确认步骤须写入标准操作程序（SOP），不得跳过。

### 3.2 高压作业人员资质

- 高压作业人员必须持有国家认证的电工操作证（高压电工作业类别），证书在有效期内。
- 非持证人员严禁进行任何高压操作——包括高压设备内部检修、高压接线的连接和断开、绝缘测试等。低压操作人员（如 PLC 调试）工作中如需触及高压区域，须由持证高压电工事先断电并确认安全。
- 高压操作必须执行"一人操作、一人监护"的双人制度，监护人不得同时参与操作，专责观察和紧急响应。

## 4. 消防安全与锂电池风险

### 4.1 锂电池热失控风险管控

电池产线的核心消防安全风险来自锂电池（来料电芯、半成品模组和成品 Pack）的热失控（Thermal Runaway）风险。热失控一旦发生，会迅速释放大量热量和有毒可燃气体，且具有多米诺骨牌式的连锁传播效应。

管控措施：
- **电芯存储管理**：来料电芯存储于独立恒温恒湿仓库（温度 23±3°C，湿度≤10%RH），仓库配置 VESDA 极早期烟雾探测系统，可在热失控早期的气溶胶阶段（尚未产生可见烟雾）即发出预警。仓库内配置二氧化碳自动灭火系统。
- **产线电芯数量控制**：各工位在线电芯数量按节拍要求严格控制，尽量降低同一时刻产线上暴露的电芯总量。异常电芯（外观鼓包、漏液、严重发热）须在发现后立即隔离至专用防火防爆安全柜。
- **高温监控**：关键工位（焊接、充放电测试）配备红外热成像摄像头或接触式温度传感器，在线电芯/模组表面温度实时监测，温升速率超过 5°C/min 或绝对温度超过 65°C 时自动报警并启动应急冷却程序。
- **防火分区**：电芯存储区、焊接区、测试区划分为独立的防火分区，分区之间采用耐火极限 ≥2 小时的防火墙或防火卷帘隔离。一旦某分区发生热失控，防火卷帘自动降落，将火灾限制在单个分区内。

### 4.2 金属粉尘防火防爆

激光焊接产生的铝、铜等金属粉尘在特定浓度下可能形成粉尘爆炸混合物。管控措施：

- 排烟系统高效运行，确保焊接工作腔体内的粉尘浓度始终低于爆炸下限（LEL，Lower Explosive Limit）的 25%
- 排烟管道和粉尘收集箱使用防静电材质，设备和管道系统有效接地，防止静电火花点燃粉尘
- 粉尘收集箱每班或每日清理，不允许粉尘长期积聚
- 激光焊接区域严禁使用会产生火花的工具（如普通钢制扳手——使用铍铜防爆工具代替）

### 4.3 消防设施配置

产线消防设施按类别配置如下：

- **自动灭火系统**：电芯仓库配置二氧化碳自动灭火系统；电气设备间配置七氟丙烷（HFC-227ea）气体灭火系统（不导电、无残留，适合保护精密电气设备）；办公区和通道配置自动喷水灭火系统。
- **手持灭火器**：各工位附近配置适用于不同火源类型的灭火器——A/B/C 干粉灭火器（适用固体、液体和电气火灾）、二氧化碳灭火器（适用电气和精密仪器火灾）、D 类灭火器（适用锂电池金属火灾，如锂、钴等）。灭火器每月点检一次压力表读数是否在绿区，每年由消防维保单位进行专业检验。
- **紧急疏散**：紧急疏散通道宽度 ≥1.2 米，始终保持畅通无阻——严禁在疏散通道上存放物料、工具或停放 AGV。疏散出口设置带应急照明的"安全出口"标识，应急照明在断电后可持续工作 ≥90 分钟。每个班次每名员工须知晓距其工位最近的至少两个疏散出口的位置。

## 6. 应急响应预案

产线应急响应预案覆盖以下场景，每类场景有明确的应急处理流程（ERP，Emergency Response Procedure）：

- **锂电池热失控应急**：发现电芯/模组/Pack 异常发热、冒烟或起火 → 立即按下就近的紧急停机按钮 → 通过内部广播发布火灾警报和疏散指令 → 现场人员沿疏散路线撤离至安全集合点 → 消防控制室确认自动灭火系统是否启动 → 拨打119报警（说明火灾性质为锂电池火灾） → 禁止使用水或普通灭火器扑灭锂电池火灾（锂电池火需要 D 类灭火器或大量持续水冷却包覆灭火）
- **激光辐射暴露应急**：人员疑似眼部受到激光辐射 → 立即停止激光器 → 辅助受伤人员离开危险区 → 不可揉搓眼睛 → 立即送医眼科检查，携带激光器波长和功率参数信息以便医生评估 → 保留事故现场和激光参数记录用于后续调查
- **化学品泄漏应急**：小量泄漏（<1L）→ 操作者佩戴 PPE 用泄漏应急包中的吸附材料围堵和吸收泄漏物 → 将污染物放入专用危废容器 → 记录泄漏化学品名称和量；大量泄漏（≥1L）→ 立即疏散该区域人员 → 通知应急响应小组 → 启动排风系统 → 应急小组使用专业防护装备处理
- **高压电击应急**：发现人员触电 → 不直接用手拉扯触电者 → 立即按下最近的紧急断电按钮或使用绝缘杆移开电源线 → 检查伤者意识和呼吸 → 如无反应无呼吸立即开始 CPR（心肺复苏）→ 同时呼叫急救电话120 → 保护现场对事故原因做初步判断和记录

## 7. 参数说明

| 参数 | 说明 | 标准值 | 风险 |
|------|------|--------|------|
| 接地电阻（高压设备） | 高压设备保护接地电阻 | ≤0.1Ω | 接地电阻过大致使漏电保护失效 |
| 接地电阻（一般设备） | 一般电气设备保护接地电阻 | ≤10Ω | 接地电阻过大漏电保护灵敏度降低 |

| 电芯存储湿度 | 电芯仓库环境相对湿度 | ≤10%RH | 湿度过高导致极柱氧化和绝缘下降 |
| 粉尘浓度上限 | 焊接区粉尘浓度与LEL比例 | <25% LEL | 接近LEL时粉尘爆炸风险显著增加 |
| 疏散通道宽度 | 紧急疏散通道最小宽度 | ≥1.2m | 宽度不足疏散人员通过能力受限 |
| 应急照明持续 | 断电后应急照明持续供电时间 | ≥90分钟 | 时间不足大型厂房人员疏散未完成 |
| 灭火器点检频率 | 灭火器压力表目视检查频率 | 每月1次 | 点检疏漏可能灭火器在关键时刻失效 |
| LOTO锁具个人化 | 上锁挂牌使用个人专用锁具 | 每人独立锁+钥匙 | 共用锁具无法保证单人控制能量的安全 |
| 安全培训复训频率 | 全员安全知识更新培训 | 每年≥1次 | 复训间隔过长安全意识和知识衰退 |

## 8. 安全文化

安全管理制度和设施的建设只是安全管理的基础，最终的安全水平取决于每一位员工的安全意识和日常行为。产线推行以下安全文化建设举措：

- **隐患随手拍**：鼓励员工将日常工作中发现的安全隐患拍照上传至内部安全管理平台，每条有效隐患举报给予正向激励。维护部门须在规定时限内（高隐患 24 小时、中隐患 3 天、低隐患 1 周）完成整改并上传整改后照片闭环。
- **安全分享会**：每周班组班前会安排 5 分钟的安全小故事分享——由班组成员轮流讲述一个亲身经历或身边发生的安全事故或未遂事件（Near Miss），通过真实的案例触动安全意识。
- **LOTO 审计**：安全工程师每周至少进行一次 LOTO 执行情况的随机抽查审计——观察正在进行设备维维修的人员是否正确执行了 LOTO 流程。审计结果即时反馈，对执行优秀者予以表彰，对违规操作者予以再培训。
- **安全 KPI**：将安全指标纳入各层级管理人员和班组长的绩效考核，包括但不限于：可记录事故数（TRI，Total Recordable Incidents）、隐患按时整改率、安全培训完成率、LOTO 审计合规率。安全管理不是安全部门一个部门的事，而是每个管理者不可分拆的责任。
