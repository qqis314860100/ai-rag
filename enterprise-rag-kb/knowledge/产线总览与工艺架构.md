# 产线总览与工艺架构

## 1. 概述

本产线为动力电池 Pack 智能生产线，涵盖从单体电芯来料至成品 Pack 下线的全流程。产线年产能设计为 12 GWh，单班配置，线体总长约 180 米，占地面积约 4500 平方米。产线采用分段式工艺布局，从前段电芯处理到 Pack 总装，依次划分为：电芯分选区、模组组装区、激光焊接区、检测区、Pack 总装区、Pack EOL 测试区、成品下线区。

产线控制系统采用 PLC+SCADA 架构，通过 MES 系统实现全流程生产追溯。各工位配备工业触摸屏，支持操作引导、参数显示、异常报警等功能。产线设计参考 IATF 16949 质量管理体系要求，关键工序 CPK 目标不小于 1.33。

## 2. 工艺流程图

```
电芯来料检测 -> 电芯分选(CS-010) -> 电芯堆叠(MA-020) -> 精密涂胶(MA-020)
    -> 端板侧板装配 -> 激光焊接(MW-030) -> Busbar 激光焊接(MW-040)
    -> 模组 EOL 测试(MT-050) -> 模组缓存 -> Pack 总装(PA-060)
    -> Pack EOL 测试(PT-070) -> 成品下线 -> 入库
```

## 4. 产线节拍要求

产线节拍设计以 Pack 下线为目标：

- 单线有效作业时间：22 小时/天（含 2 小时换型、点检、用餐）
- 设计产能：120 Pack/天（50Ah电芯，1P96S及以上配置）
- 整线 OEE 目标：≥ 85%
- 瓶颈工位：MW-030/MW-040（激光焊接工位），单工位节拍 4 PPM

产能爬坡计划分三阶段：

| 阶段 | 时间 | 目标产能 | 关键措施 |
|------|------|----------|----------|
| SOP | 第1-2月 | 60 Pack/天 | 工艺验证、人员培训、单站调试 |
| 爬坡期 | 第3-4月 | 90 Pack/天 | 节拍优化、并行工位启用、夹具优化 |
| 达产期 | 第5月起 | 120 Pack/天 | 全线联动、MES全面上线、TPM体系运行 |

## 5. 产线布局原则

- 物流流向为 U 型布局，来料与成品出口靠近物流通道
- 电芯存储区与产线隔离，恒温恒湿控制（温度 23±3°C，湿度 ≤10% RH）
- 激光焊接区设置独立隔间，配备防激光辐射防护帘
- 检测区独立接地，接地电阻 ≤1Ω
- Pack 总装区配备 AGV 搬运系统
- 各工位设置目视化管理看板，包括 SOP、点检表、异常对应表

## 6. 质量控制体系

产线质量控制采用以下层级：

- IQC（来料检验）：电芯、Busbar、结构件来料抽检
- IPQC（过程检验）：各工位过程参数 SPC 监控
- FQC（成品检验）：模组 EOL 和 Pack EOL 全检
- OQC（出货检验）：Pack 出货前抽查

关键质量指标（KPI）：

| KPI | 目标值 | 监控频率 |
|-----|--------|----------|
| 模组一次合格率 | ≥98% | 每班 |
| Pack 一次合格率 | ≥97% | 每班 |
| 激光焊缝合格率 | ≥99.5% | 每班 |
| 涂胶重量 CPK | ≥1.33 | 每天 |
| CCD 误判率 | ≤0.5% | 每班 |

## 7. 安全注意事项

- 激光作业区必须配备防护眼镜（OD≥6），入口设置安全连锁开关
- 涂胶区域配备局部排风系统，操作人员佩戴防有机溶剂口罩
- 电芯存储区禁止烟火，配备温度监控和自动灭火系统
- EOL 测试区高压区域明确标识，配备绝缘垫和高压警示灯
- 所有旋转和移动部件必须配备防护罩和安全光幕
- 紧急停机按钮间距不超过 5 米
- 新员工必须完成安全培训并通过考核方可上岗
