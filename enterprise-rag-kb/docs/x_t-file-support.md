# X_T 文件支持方案研究

## 一、X_T 文件简介

X_T 文件属于 Siemens Parasolid 实体建模内核的文本格式，用于存储 3D 产品零件模型。

- **内容**：三维几何、颜色信息、元数据，均以文本形式保存
- **对比**：X_B 是其二进制版本；X_T 是可读文本格式
- **前身**：替代 XMT_TMT 文件格式
- **兼容软件**：NX、Inventor、SolidWorks 等 CAD 程序

---

## 二、核心约束

**内部数据不能通过外网传输。** 所有方案必须支持完全内网部署，云端服务（Autodesk APS、CAD Exchanger Cloud 等）全部排除。

---

## 三、在线 3D 渲染方案（已排除）

| 方案 | 描述 | 排除原因 |
|------|------|----------|
| Autodesk Platform Services (APS) | 原生支持 X_T，云端转换渲染 | 文件需上传至 Autodesk 外网 |
| CAD Exchanger Cloud | 支持 X_T，REST API | 云端服务，数据出网 |
| Hoops Communicator (云模式) | 支持 Parasolid，WASM 渲染 | 云端授权验证 |

---

## 四、内网可用方案

### 4.1 商业 SDK 本地部署（精度最高）

**Hoops Communicator（Tech Soft 3D）**
- 原生支持 Parasolid X_T，解析完整度最高
- 可完全部署在内网服务器，有 WASM 版本
- 缺点：商业授权，需采购

**CAD Exchanger SDK**
- 支持 X_T，提供本地部署 License
- 可封装为内网 REST API 服务

### 4.2 开源链路（X_T 支持有限）

```
X_T → FreeCAD CLI（本地）→ GLTF/OBJ → Three.js 浏览器渲染
```

- FreeCAD 通过 OpenCASCADE (OCCT) 读取 X_T
- 局限：Parasolid 是专有格式，复杂模型可能丢失特征
- 适合：模型简单、对精度要求不高的场景

### 4.3 截图预览（实现最简单）

```
X_T → FreeCAD headless 渲染 → PNG 缩略图 → 前端展示
```

- 无需 3D 交互，只返回预览图
- 实现简单，适合 RAG 知识库附图场景

## 五、推荐方向：文本描述 + 缩略图（最适合 RAG）

### 5.1 可行性

X_T 是**纯文本格式**，不需要完整 CAD 内核即可读取部分内容：
- 零件名称、属性标签
- 几何实体类型与数量
- 颜色、材质信息
- 装配树层级结构

### 5.2 完整处理管道

```
X_T 文件上传
     ↓
① 文本直接解析（Python，零依赖）
   → 零件名、属性、颜色、实体统计
     ↓
② FreeCAD Python（内网部署）
   → 包围盒尺寸、体积、面数、装配层级
   → 缩略图截图（PNG）
     ↓
③ 模板生成 or 本地 LLM（可选）
   → 自然语言描述
     ↓
文本描述 + 缩略图 → 存入 RAG 知识库索引
```

### 5.3 输出示例

```
零件名称：电池模组端板
文件类型：Parasolid X_T（文本格式）
主体结构：1 个顶层装配，包含 3 个子零件
几何信息：
  - 外形尺寸（包围盒）：约 320mm × 140mm × 8mm
  - 总面数：48，含 6 个圆柱孔特征
  - 体积：约 285,000 mm³
材质属性：Steel（灰色 #808080）
关键特征：矩形平板结构，边缘含倒角，均布 6 个 M6 安装孔
```

### 5.4 实现难度

| 步骤 | 技术 | 难度 | 外部依赖 |
|------|------|------|----------|
| 文本解析提取元数据 | Python 正则 / 文本解析 | 低 | 无 |
| 几何属性提取 | FreeCAD headless Python | 中 | 内网部署 FreeCAD |
| 生成缩略图 | FreeCAD OffscreenRenderer | 中 | 同上 |
| 自然语言描述 | 模板生成 or 本地 LLM | 低-中 | 纯模板无需 LLM |

## 六、选型建议

| 需求场景 | 推荐方案 |
|----------|----------|
| 只需看外观缩略图 | FreeCAD headless 截图 |
| 需要交互旋转/剖面 | FreeCAD + Three.js（接受精度损失） |
| 工业级精度要求 | 商业 SDK（Hoops/CAD Exchanger），谈内网 License |
| RAG 知识库集成 | 文本解析 + FreeCAD 几何提取 + 模板描述 |

---

## 七、与现有 RAG 系统集成

当前项目已有文件上传管道（`/data/uploads/`），扩展思路：

1. 上传 X_T 文件 → 调用本地 FreeCAD 服务解析
2. 提取结构化元数据（零件名、尺寸、特征）
3. 生成文本描述 → 送入向量化 + 检索索引
4. 缩略图 PNG → 存储并关联到知识库条目
5. 用户提问"有没有端板的 CAD 文件" → RAG 检索命中并展示缩略图
