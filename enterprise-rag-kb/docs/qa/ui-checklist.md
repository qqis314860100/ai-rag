# UI 验收清单

版本: v1.0 | 创建日期: 2026-05-16 | 适用系统: 企业级电池产线 RAG 知识库

---

## 通用说明

本清单用于前端 UI 的验收测试，覆盖 Dashboard、文档管理、智能问答、检索调试、响应式布局、错误状态 6 大模块。验收人逐项测试后填写"通过/失败/不适用"，并在备注中记录问题详情。

## 6. 错误状态展示

| # | 检查项 | 预期行为 | 结果 | 备注 |
|---|--------|----------|------|------|
| E-01 | API 连接失败 | 当后端 API 不可达时，展示"服务不可用"友好提示而非白屏 | | |
| E-02 | 网络超时 | 请求超时后展示重试按钮或自动重试选项 | | |
| E-03 | 400 参数错误 | 发送空消息或无效参数时展示具体字段错误提示 | | |
| E-04 | 403 权限不足 | 无权限访问的功能/页面展示"权限不足"提示 | | |
| E-05 | 404 资源不存在 | 访问不存在的文档/会话时展示"资源不存在"提示 | | |
| E-06 | 500 服务端错误 | 服务端异常时展示"服务器遇到错误，请稍后重试"，不泄露堆栈 | | |
| E-07 | 文件上传错误 | 上传失败（网络中断、文件格式不支持、超限）展示明确原因 | | |
| E-08 | 空搜索结果 | 搜索无结果时展示"未找到相关内容"提示 | | |
| E-09 | 浏览器兼容性 | 主流浏览器（Chrome、Edge、Safari）功能正常 | | |
