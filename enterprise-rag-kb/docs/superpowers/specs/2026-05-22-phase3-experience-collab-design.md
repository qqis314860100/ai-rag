## 1. 搜索体验改进

### 1.1 搜索建议 (Autocomplete)

- 用户输入时，前端 debounce 300ms 后调 `/api/search/suggest?q=xxx`
- 后端从已有查询历史 + 文档标题中匹配 top 5 建议
- 下拉菜单展示，点击直接搜索

### 1.2 搜索历史

- 用户每次搜索自动保存到 `search_history` 表
- 搜索框 focus 时展示最近 5 条搜索历史
- 支持一键清除历史

### 1.3 热门问题

- Dashboard 侧边栏展示"本周热门问题 Top 10"
- 基于搜索频率 + 反馈点赞数排序
- 点击直接跳转聊天页发送该问题

### 1.4 数据模型

```sql
CREATE TABLE search_history (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  query TEXT NOT NULL,
  result_count INTEGER,
  created_at TEXT NOT NULL
);
```

## 2. 首页个性化

### 2.1 方案

按用户角色 + 部门展示不同首页内容：

| 角色 | 首页内容 |
|------|---------|
| 产线操作工 | SOP 快速入口、今日告警、常见故障速查 |
| 工艺工程师 | 工艺参数速查、最近更新的文档、调试工具入口 |
| 质量工程师 | 质量标准文档、检测指标速查、不合格品处理指南 |
| 设备维护 | 设备故障维护手册、备件清单、保养周期提醒 |

### 2.2 实现

- Dashboard 根据 `user.role` + `user.department` 条件渲染不同卡片组
- 每个角色配置一个 JSON 定义"推荐文档列表" + "快捷入口"

## 3. 批量导入

### 3.1 方案

- 支持 ZIP 上传（解压后逐个导入）
- 支持 Excel 导入（第一列标题，第二列内容，第三列分类）
- 上传进度条（WebSocket 或轮询）
- 导入结果报告（成功 N 篇，失败 M 篇 + 原因）

### 3.2 API

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/documents/import/zip` | POST | ZIP 批量导入 |
| `/api/documents/import/excel` | POST | Excel 批量导入 |
| `/api/documents/import/progress/:taskId` | GET | 查询导入进度 |

## 4. 文档关联

## 5. 知识卡片分享

### 5.1 方案

- 每条 AI 回答可生成"知识卡片"：标题 + 摘要 + 来源 + 二维码
